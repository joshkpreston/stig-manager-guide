Quick Reference

The Three Required Pieces

No matter how you deploy it, STIG Manager always needs exactly three things:

ComponentWhat It DoesOptions
STIG Manager The app itself — API + web UI Container, binary, or from source
MySQL 8.4+ Stores all data (the app is stateless) Docker, managed (RDS), or self-hosted
OIDC Provider Authentication — "who are you?" Keycloak, Okta, Azure Entra, F5

RepoPurpose
