Environment Variables Reference Every configuration knob for STIG Manager

STIG Manager is configured entirely through environment variables. No config files. This makes container deployment straightforward.

Minimum Required Configuration

For a basic deployment, you only need to set these:

STIGMAN_DB_HOST=your-mysql-server
STIGMAN_DB_PASSWORD=your-db-password
STIGMAN_OIDC_PROVIDER=https://your-keycloak/realms/stigman

Everything else has sensible defaults.

STIGMAN_DB_HOSTlocalhostMySQL hostname or IP
STIGMAN_DB_PORT3306MySQL TCP port

STIGMAN_DB_PASSWORDnoneDatabase password (not needed if using TLS client cert auth)
STIGMAN_DB_SCHEMAstigmanDatabase/schema name

VariableDescription

STIGMAN_DB_TLS_CERT_FILEPEM client cert for mutual TLS auth to DB
STIGMAN_DB_TLS_KEY_FILEPEM client key for mutual TLS auth to DB

JWT Claim Mapping

If your OIDC provider uses different claim names than the Keycloak defaults, override them here:

VariableDefaultWhat It Maps
STIGMAN_JWT_USERNAME_CLAIMpreferred_usernameThe user's unique username
STIGMAN_JWT_NAME_CLAIMnameDisplay name
STIGMAN_JWT_EMAIL_CLAIMemailEmail address
STIGMAN_JWT_PRIVILEGES_CLAIMrealm_access.rolesUser privileges (admin, create_collection). Array of strings.
STIGMAN_JWT_SCOPE_CLAIMscopeAPI scopes. Okta/Azure use scp instead.
STIGMAN_JWT_SERVICENAME_CLAIMclientIdService account client name
STIGMAN_JWT_ASSERTION_CLAIMjtiAssertion ID (ADFS/Azure may use uti)
STIGMAN_JWT_AUD_VALUEnoneIf set, aud claim must include this value
