STIGMan Watcher

github.com/NUWCDIVNPT/stigman-watcher

A command-line utility that monitors filesystem directories and automatically imports .ckl, .cklb, and XCCDF scan results into STIG Manager collections.

How It Works

Scanner (SCC / Evaluate-STIG / other) │ └→ Outputs .ckl or XCCDF to a watched directory │ └→ STIGMan Watcher detects new files │ └→ Imports into STIG Manager via API │ └→ Collection updated in real-time

Key Details

  • Node.js CLI — install globally: npm install -g stigman-watcher
  • Also available as an npm package: npmjs.com/package/stigman-watcher
  • Authenticates to STIG Manager as a service account (client_credentials flow)
  • Can run multiple instances, each watching different directories for different collections
  • The Watcher's service account needs a Grant in the target collection

Use Case

You have SCC (SCAP Compliance Checker) running nightly scans across 200 servers. It dumps XCCDF results to a network share. One STIGMan Watcher instance monitors that share and auto-imports everything into your "Production Servers" collection. By morning, your STIG Manager dashboard reflects the latest scan results.

STIGMan Orchestration

github.com/NUWCDIVNPT/stigman-orchestration

A reference Docker Compose deployment demonstrating STIG Manager with CAC/PKI authentication.

What's Included

  • nginx — reverse proxy configured for mTLS (CAC client cert auth)
  • Keycloak — OIDC provider with pre-configured realm
  • MySQL — database
  • STIG Manager — the app
  • Sample TLS certificates and Keycloak realm configuration

This is a reference implementation for learning and as a starting point. The sample certificates are for testing only. Customize everything for your environment before any real use.

Integration

C-PAT (Crane POA&M Automation Tool)

github.com/NSWC-Crane/C-PAT

Developed by NSWC Crane, C-PAT integrates with STIG Manager's API to automate vulnerability documentation and POA&M tracking throughout the RMF process.

What It Does

  • Pulls findings from STIG Manager collections via the API
  • Automates POA&M creation and tracking
  • Manages the vulnerability documentation lifecycle
  • Bridges the gap between STIG assessment and eMASS submission

External Tools That Work With STIG Manager

ToolRelationshipNotes
Evaluate-STIG Produces .ckl files that STIG Manager imports PowerShell-based scanner by NSWC Crane. Requires CAC to download.
SCC (SCAP Compliance Checker) Produces XCCDF results that STIG Manager imports DISA's official SCAP scanner
STIG Viewer Produces/consumes .ckl files DISA's desktop checklist viewer. STIG Manager can import and export .ckl files for interoperability.
eMASS Receives POA&M data STIG Manager generates POA&M spreadsheets as input for eMASS. Not a direct integration.
Keycloak OIDC provider The recommended (and most tested) auth provider. Supports CAC via identity brokering.

The Full Automated Pipeline

At maximum maturity, the ecosystem works together like this:

┌─────────────────────────────────────────────────────────┐ │ SCANNING LAYER │ │ SCC Evaluate-STIG Other SCAP Tools │ │ └─────────┴───────────┴─────────┘ │ │ │ .ckl / XCCDF files │ └───────────────┬─────────────────────────────────────────┘ │ ┌───────────────┴─────────────────────────────────────────┐ │ IMPORT LAYER │ │ STIGMan Watcher (auto-import) │ │ Manual import via Web UI │ └───────────────┬─────────────────────────────────────────┘ │ ┌───────────────┴─────────────────────────────────────────┐ │ MANAGEMENT LAYER │ │ STIG Manager (API + Web UI) │ │ Collections / Assets / Reviews / Metrics │ └───────────────┬─────────────────────────────────────────┘ │ ┌───────────────┴─────────────────────────────────────────┐ │ OUTPUT LAYER │ │ C-PAT (POA&M) Metrics API .ckl Export Reports │ └─────────────────────────────────────────────────────────┘
