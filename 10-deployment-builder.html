Deployment Approach

Recommended

Reference Orchestration

Use the official stigman-orchestration repo. Includes nginx (CAC/mTLS), Keycloak (pre-configured realm + x509 user creation), MySQL, and STIG Manager. Ready to run.

Flexible

Build Custom Config

Pick each component yourself. Choose your own OIDC provider, database, and proxy setup. More control, more configuration.
